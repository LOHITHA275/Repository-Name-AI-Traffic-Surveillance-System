AI Traffic Surveillance System

Features:
- Vehicle License Plate Detection using YOLOv8
- OCR using EasyOCR
- Automatic Number Plate Recognition (ANPR)
- SQLite Database Storage
- Flask Dashboard
- Bulk Image Processing

Tech Stack:
- Python
- YOLOv8
- OpenCV
- EasyOCR
- SQLite
- Flask

How to Run:
1. pip install -r requirements.txt
2. python process_all_images.py
3. python app.py
